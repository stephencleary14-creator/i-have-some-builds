Thumbnail Review

Four decisions. Pick one option per question — then we'll build it.

Decision 1

Icon Style

How the icons are drawn. Shown here using the social copywriter post as a test case.

Option A — Bold geometric

Flat, solid, high contrast. Strong at small sizes. Matches the Inter typeface's clean character.

Option B — Outlined / line icon

Lighter, editorial feel. More breathing room. Works well where the card already has strong red accents.

Option C — Icon + category label

Icon plus a small category tag. Adds information to the thumbnail — useful when you have multiple series running.

Decision 2

Colour

Icon colour and background. All four entry icons shown side by side for each option.

Option A — Red on cream

Punchy, on-brand, matches the red accent used in cards and nav. Each icon reads clearly against the warm background.

Option B — Dark on cream

Quieter, more editorial. Lets the red card border do the accent work. Better if you add more colour in the icon itself later (e.g. brand swatches entry).

Decision 3

Featured Card Treatment

The latest/hero post sits above the archive grid. Should it use the same thumbnail, or something different to distinguish it?

Option A — Same thumbnail, left panel

Consistent with the archive cards. Icon sits large in the left half of the hero card — simple and tidy.

Option B — Dark panel, coloured icon

Dark background on the image half elevates the hero card above the archive grid. Red icon pops against navy — more editorial drama.

Option C — Full-width banner above text

Drops the side-by-side layout. Icon banner spans full width above the text, and scales naturally on mobile without any layout switching needed.

Decision 4

Mobile Behaviour

How the archive cards look on a narrow screen. Currently the image is hidden entirely.

Option A — Compact icon banner

Short 64px strip at the top of each card. Icon is small but legible. Adds visual identity without eating up screen space.

Option B — Accent strip only

A thin cream strip sits above the red border, giving a layered look without any image. Text-first, nothing to distract. Clean but minimal.

Option C — Hidden (current behaviour)

Keep the current mobile layout untouched. The new designed thumbnails only appear on desktop where they render well. Text-first on mobile.
